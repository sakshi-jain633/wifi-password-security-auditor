## Project Overview

Wi-Fi Password Security Auditor is a Python-based cybersecurity tool developed to assess the strength of Wi-Fi passwords. The application analyzes passwords against essential security parameters and provides a detailed security assessment along with recommendations for improving password strength.

The objective of this project is to promote secure password practices and enhance awareness of wireless network security.

---

## Key Features

- Password strength evaluation
- Security score calculation
- Weak, Medium, and Strong password classification
- Common password detection
- Security recommendations
- User-friendly command-line interface
- Real-time password security assessment

---

## Technologies Used

- Python 3
- Regular Expressions (re Module)

---

## Working Methodology

The tool evaluates a password based on the following security criteria:

- Minimum password length
- Presence of uppercase letters
- Presence of lowercase letters
- Presence of numeric characters
- Presence of special characters
- Detection of commonly used passwords

Based on these parameters, a security score is generated and the password is categorized as Weak, Medium, or Strong.

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash

```

4. Enter a Wi-Fi password when prompted.
5. View the generated security report.
